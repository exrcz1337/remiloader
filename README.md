# remiloader

Simple Telegram video downloader bot.

## How to use

1. Clone this repo:
   ```bash
   git clone https://github.com/exrcz1337/remiloader.git
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Create .env with your token:
   ```env
   TOKEN=yourtoken
   ```

4. Run the bot:
   ```bash
   python remiloader.py
   ```
